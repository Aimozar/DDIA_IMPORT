# 12 周 DDIA Java 后端学习路线

## 第 1 周：建立系统设计框架

学习：ch1、glossary。

输出：数据系统组件图；可靠性、可伸缩性、可维护性总结；10 个核心术语解释。

## 第 2 周：数据模型

学习：ch2。

输出：关系模型、文档模型、图模型对比；用订单系统设计三种数据模型。

## 第 3-4 周：存储与检索

学习：ch3。

输出：B-Tree 和 LSM Tree 对比；MySQL 索引学习笔记；慢 SQL 分析模板。

实验：写一个简单 append-only log KV 存储。

## 第 5 周：编码与演化

学习：ch4。

输出：JSON / Protobuf / Avro 对比；API 兼容性设计清单。

## 第 6 周：复制

学习：ch5。

输出：主从复制图；读写分离风险清单；主从延迟处理方案。

实验：模拟 leader-follower 日志复制。

## 第 7 周：分区

学习：ch6。

输出：分库分表设计模板；分区键选择原则；热点数据解决方案。

实验：hash 分区模拟；一致性哈希模拟。

## 第 8 周：事务

学习：ch7。

输出：ACID 总结；隔离级别对比；库存扣减事务设计。

实验：用 MySQL 复现丢失更新、不可重复读、幻读。

## 第 9 周：分布式系统故障

学习：ch8。

输出：超时、重试、幂等设计清单；微服务故障案例分析。

实验：模拟接口超时后重复下单。

## 第 10 周：一致性与共识

学习：ch9。

输出：线性一致性解释；Redis 分布式锁风险分析；ZooKeeper / etcd 用途总结。

## 第 11 周：批处理与流处理

学习：ch10、ch11。

输出：Kafka 消费语义总结；订单事件流设计；CDC 同步方案。

实验：订单事件 → MQ → 消费者 → 统计表。

## 第 12 周：系统设计综合

学习：ch12。

输出三个系统设计案例：订单系统、秒杀系统、日志分析系统。

每个案例必须覆盖：数据模型、存储选择、索引、缓存、复制、分区、事务、一致性、消息队列、故障恢复。
