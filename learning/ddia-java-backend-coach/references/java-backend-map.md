## Java 后端常见问题对应 DDIA 章节

### MySQL 查询慢

重点读：ch3 存储与检索、ch7 事务。

关注：索引结构、写放大、查询模式、事务隔离。

### 缓存不一致

重点读：ch1 可靠性、ch5 复制、ch11 流处理、ch12 派生数据。

关注：缓存是派生数据、失效策略、事件驱动更新、最终一致性。

### 订单超卖

重点读：ch7 事务、ch8 分布式系统的麻烦、ch9 一致性与共识。

关注：事务边界、隔离级别、幂等、分布式锁风险。

### 消息重复消费

重点读：ch11 流处理、ch8 分布式系统的麻烦。

关注：至少一次投递、幂等消费、去重表、业务唯一键。

### 分库分表

重点读：ch6 分区、ch7 事务、ch9 一致性与共识。

关注：分区键、热点数据、跨分片查询、跨分片事务。
