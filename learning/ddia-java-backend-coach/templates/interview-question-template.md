# DDIA Java 后端面试题模板

## 基础题

1. 什么是可靠性、可伸缩性、可维护性？
2. 数据库为什么需要索引？
3. 什么是主从复制？
4. 什么是事务？
5. 什么是消息队列？

## 进阶题

1. B-Tree 和 LSM Tree 有什么区别？
2. MySQL 主从延迟会导致什么问题？
3. 分库分表后跨库事务怎么处理？
4. MySQL 的 MVCC 是什么？
5. Kafka 为什么能支持高吞吐？

## 实战题

1. 如何设计一个不会超卖的秒杀系统？
2. 支付回调重复通知如何保证幂等？
3. Redis 缓存和 MySQL 数据不一致怎么办？
4. MQ 消息消费成功但数据库更新失败怎么办？
5. 订单系统如何做最终一致性？

## 标准回答结构

回答每个问题时按：

1. 一句话定义
2. 解决什么问题
3. 核心机制
4. Java 后端例子
5. 常见坑
6. 总结
