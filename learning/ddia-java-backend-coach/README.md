# DDIA Java 后端学习教练

这是一个面向 Java 后端开发者的 DDIA 学习 Skill。

它的目标不是复刻《Designing Data-Intensive Applications》原书，而是帮助 Java 后端开发者把书中的数据系统知识转化为工程能力。

## 适合谁

- Java 后端开发者
- 想从 CRUD 进阶到中高级后端的人
- 想理解 MySQL、Redis、Kafka、Elasticsearch 背后原理的人
- 准备后端架构、分布式系统、数据库相关面试的人
- 想做订单、支付、秒杀、IM、日志、推荐等复杂系统的人

## 核心能力

- 解释 DDIA 概念
- 设计学习路线
- 生成章节笔记
- 映射 Java 后端技术栈
- 设计实验
- 生成面试题
- 分析系统设计案例

## 推荐学习顺序

第一轮：

```text
ch1 → ch3 → ch5 → ch6 → ch7 → ch8 → ch9 → ch11
```

第二轮：

```text
ch2 → ch4 → ch10 → ch12
```

## 如何和 AI 配合使用

把 `SKILL.md` 上传给 ChatGPT、Cursor、Claude 或其他 AI 工具，然后输入：

```text
请读取这个 SKILL.md，并按照 DDIA Java 后端学习教练的方式回答我后续问题。
```

之后可以这样提问：

```text
用 Java 后端视角帮我学习 DDIA 第 7 章事务。
```

```text
用 DDIA 的思想分析订单系统如何保证最终一致性。
```

```text
请结合 MySQL、Redis、Kafka 解释 DDIA 中的派生数据。
```
